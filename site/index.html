Two-Phase Page-Locked Volatile Memory

Plaintext secrets never exist as immutable Python str or bytes objects in the parent wait loop. Envshield locks 4KB-aligned virtual memory pages so the OS kernel never swaps secrets to NVMe, and executes deterministic ctypes.memset zeroing before unlocking pages on exit.

08 // Security & Licensing FAQ

Technical questions, answered directly.

If an adversary has compromised kernel ring 0 or root on a host, any running process can theoretically be inspected. Envshield is engineered to defeat the five highest-probability real-world breach vectors: (1) plaintext .env files persisted on SSDs/backups, (2) OS swap-file paging via mlock()/VirtualLock(), (3) non-root adjacent process ptrace/core-dumps via prctl(PR_SET_DUMPABLE, 0), (4) world-readable /proc/<pid>/cmdline and docker inspect leaks, and (5) accidental traceback credential prints to CI/CD logs.

The updated .env.enc is committed to Git; Alice unlocks it locally using ~/.ssh/id_ed25519.
