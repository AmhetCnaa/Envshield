Hardened Defense-in-Depth

Engineered For Paranoid Security Engineers

Most secrets management tools claim to be "secure" while leaving plaintext .env files lying on developer NVMe drives, leaking secrets into terminal history, or failing completely during SaaS provider outages. Envshield fixes the root causes.

1. Zero-Disk RAM Invariant

Decryption occurs strictly in locked memory buffers (VirtualLock on Windows, mlock on Linux/macOS) with PR_SET_DUMPABLE=0. Secrets never touch SSD inodes, OS swap, or temp directories.

✓ ctypes.memset zeroing on exit

2. Live Stream Redactor

Sliding-window lookahead redactor monitors child process stdout and stderr streams. Handles chunk-split tokens, multi-byte UTF-8 boundaries, Base64, and URL-encoded secrets.

✓ Zero terminal / CI log leaks

3. Docker Stealth Mount

Bypasses insecure docker run -e KEY=VAL flags that expose credentials to ps aux and /proc. Injects secrets via ephemeral /dev/shm RAM tmpfs with 0o400 permissions.

✓ docker inspect shows 0 secrets

4. Canary Honeypot Engine

When an unauthorized attacker or rogue script guesses passwords, Envshield silently feeds fake high-entropy honeypot credentials and triggers a silent incident alarm to your security webhook.

✓ Immediate breach telemetry

Frequently Asked Questions

Direct technical answers to the most common architecture and licensing questions.

How does Envshield differ from Doppler, 1Password CLI, or HashiCorp Vault?

Doppler and 1Password are centralized SaaS platforms: if their cloud API is down or you lose internet access, your local development and CI/CD pipelines halt. HashiCorp Vault requires running and maintaining complex server clusters. Envshield is 100% decentralized and local-first: cryptographic envelopes live directly in your Git repository, unlockable offline with local SSH keys or via Cloud KMS in CI/CD without SaaS lock-in or cluster management fees.

What is the Threat Model? Can root or a kernel debugger dump memory?

In computer security, if an adversary has complete root / kernel ring 0 compromise, all software running on that machine can technically be inspected. Envshield's threat model specifically protects against the most common, high-severity real-world vectors: (1) cold-boot disk scrapes and unencrypted backup leaks, (2) OS swap memory paging via mlock() / VirtualLock(), (3) unprivileged adjacent process memory inspection via prctl(PR_SET_DUMPABLE, 0), (4) docker inspect and ps aux environment snooping, and (5) terminal log / CI traceback credential leakage.

How does team SSH key sharing work without a central server?

Envshield uses RFC 9180 (HPKE) and Envelope v2 cryptographic recipient blocks. When you run envshield team add alice --github, Envshield fetches Alice's public Ed25519 or RSA SSH keys from GitHub via HTTPS. The Data Encryption Key (DEK) is encrypted individually for each authorized team recipient. Each developer decrypts the vault using their own local SSH private key (~/.ssh/id_ed25519) without ever needing a shared master password.

Why did you choose GNU AGPLv3 for the open-source edition?

The GNU Affero General Public License (AGPLv3) prevents massive cloud hyperscalers and venture-funded SaaS corporations from taking our independent open-source security engine, hosting it as a closed proprietary service, and locking developers into expensive monthly tiers without giving back to the community. Developers and open-source contributors can use Envshield completely free forever. Enterprises requiring commercial AGPL waivers can purchase our Team or Enterprise licenses.
